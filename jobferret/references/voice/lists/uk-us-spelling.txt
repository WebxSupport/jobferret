# uk-us-spelling.txt
# What this is: spelling pairs for a locale-consistency check. Format: uk-form,us-form (one pair
# per line, lowercase). voice_lint uses it for check 10 (voice match, locale part): in a UK
# document (locale uk, or profile spelling en-GB) any us-form is a flag; in a US document any
# uk-form is a flag. Mixed spelling inside one document is always a flag, whatever the locale.
# The locale comes from --profile, else from config.toml [locale] default.
# Match semantics: whole word, case-insensitive. Inflections are separate pairs because there
# are no stems. Proper nouns are exempt (Pittsburgh Center, Barbican Centre, "Honours" in a
# degree title such as BSc (Hons)); the model judges, the linter reports. Skip anything inside
# a URL or email address.
# Source: 04 §1 rule 12, 04 §2.1 (Agarwal et al.: drift toward American style), 04 §3
# (American drift), 04 §5.3 (locale as an idiolect marker). The pairs cover words that
# appear in CVs and letters. The clinical block is for NHS applications.
#
# Two blocks. The split is the comment line that matches the regex ^# === BLOCK 2 (anchored).
#   Block 1: the forms belong to one locale each. Flag either direction.
#   Block 2: the US form is also correct, in some uses, in UK English. Flag ONLY the UK form,
#   and only in US documents. In UK documents never flag the US form from Block 2.
# Reasons, so nobody "fixes" the lists later:
#   program    correct in BOTH locales for software ("a computer program", "program the
#              PLC"). Programme (UK) is for a plan or a series of events.
#   licence    UK noun; "license" is the UK verb ("licensed to practise").
#   practise   UK verb; US uses "practice" for noun and verb. UK "practice" (noun) is right.
#   meter      UK English uses "meter" for devices ("smart meter", "gas meter"). Only "metre"
#              (the unit) is UK-only.
#   dialog, catalog, analog, artifact   appear in UK software writing ("dialog box").
#   cheque     "check" is valid in the UK for verifying; only the payment sense differs.
#   whilst, amongst, towards   UK-leaning register words; while, among and toward are
#              correct everywhere.
#   judgement  UK law and many UK style guides write "judgment" too.
#   tyre, kerb UK nouns; "tire" and "curb" are UK verbs.
#   enquiry    UK English uses both; "inquiry" is standard in formal investigations.
#   speciality UK clinical writing uses both "speciality" and "specialty".
#   ageing, learnt   UK English accepts "aging" and "learned".
#   mum        US "mom". Rare outside personal stories.
#
# === BLOCK 1: flag either direction ===
