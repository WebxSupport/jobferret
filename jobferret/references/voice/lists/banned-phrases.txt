# banned-phrases.txt
# What this is: multi-word phrases that must never appear in application writing. Openers and
# closers that are banned wherever they sit are here too; openers.txt and closers.txt add
# position-aware patterns on top.
# Match semantics: one entry per line; lowercase; matched case-insensitively with word
# boundaries at both ends; internal spaces match any run of whitespace (including a line break).
# Normalise curly quotes to straight ones before matching. A hit fails voice_lint check 2.
# Literal uses are exempt (a "navigate the" instruction for a satnav trainer), so the model
# judges each hit.
# Source: 04 §4 "Never use: phrases", 04 §3 (tell tables), and the cut-lists in 04 §6. The
# figurative uses of landscape, navigate, dynamic and journey (04 §4 "figurative", "about
# yourself", "career sense") are listed here as phrases because the bare words are ordinary.
